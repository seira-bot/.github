<h3>Your own team of AI agents in one chat app.</h3>

We build Seira, a free, open source desktop app for Windows and Linux.<br>
It runs Claude Code, Codex, Gemini, and more than 25 other AI agents as a team of bots in one chat.<br>
Each bot is a real agent with its own model, computer, and connected apps.<br>
You talk to your bots like contacts, watch them work, and approve the steps that matter.

### What we stand for

- **Your agents, your plans.** Bots run on the agent programs on your computer, such as Claude Code, Codex, Gemini, Cursor, and GitHub Copilot, with your own sign-in. No new account. No proxy in the middle.
- **Local first.** Chats, keys, and files stay on your computer. A bot reaches the cloud only when you connect it.
- **You approve what matters.** Commands, file edits, and questions show as cards. You allow or deny each one.
- **Open source.** The code is under the Apache License 2.0. Read it, build it, and change it.

### Get involved

- Read the [docs](https://docs.seira.bot), or [download Seira](https://seira.bot/#download) for Windows or Linux.
- Read the [README](https://github.com/seira-bot/seira#readme), then [build Seira from source](https://github.com/seira-bot/seira#quick-start).
- Send a pull request. Read [CONTRIBUTING.md](https://github.com/seira-bot/seira/blob/main/CONTRIBUTING.md) first.
- Report a security problem in private through [a security advisory](https://github.com/seira-bot/seira/security/advisories/new). Do not post it in public.
