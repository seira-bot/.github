# seira-bot/.github

This repository holds the public profile of the [seira-bot](https://github.com/seira-bot) organization.

- `profile/README.md` is the text on the organization page.
- `profile/assets/` holds the 3D logo, the wordmark, and the organization avatar (`seira-avatar.png`).

The Seira app is in [seira-bot/seira](https://github.com/seira-bot/seira).
